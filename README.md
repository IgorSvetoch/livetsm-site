# Aladdin LiveTSM

Промосайт на основе согласованной версии 3.7, выпуск 1.8.6 от 06.11.2026 с пиктограммами и официальными контактами.

Сайт: https://igorsvetoch.github.io/livetsm-site/

Сохранены структура, технические схемы, сценарии и интерфейсы CLI/GUI. Добавлены реальные фотографии модулей и единый набор иллюстраций оборудования. Пилотирование и форма запроса удалены. Блок реакций на изменение пути загрузки сохранён. Все разделы дополнены единым набором контурных пиктограмм. В подвале — общий телефон, основная почта и почта по партнёрству АО «Аладдин Р.Д.»; контакты технической поддержки не публикуются.

## Файлы

- `index.html`, `css/styles.css`, `css/pictograms.css`, `js/app.js` — сайт.
- `assets/illustrations/` — шесть SVG для семи карточек.
- `SITE-SPEC.md` и `SITE-SPEC.json` — единый первоисточник требований.
- `AGENTS.md` — правила изменений.

Перед правкой прочитайте обе спецификации и синхронно обновляйте их вместе с реализацией. Сайт статический; для локального просмотра откройте index.html. Две фотографии загружаются из публичного Sales Kit, поэтому для них требуется интернет.

PDF-руководства, материалы сертификации и внутренние архивы в публичную поставку не входят. Решение о проведении сертификации не является выданным сертификатом.
