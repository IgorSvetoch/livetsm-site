Aladdin LiveTSM — единый комплект сайта v3.7

КАК ПОСМОТРЕТЬ
- Откройте index.html в любом современном браузере.
- Интернет и веб-сервер не требуются.
- Сайт адаптирован для desktop, tablet и mobile.

ПЕРВОИСТОЧНИК ТРЕБОВАНИЙ
- SITE-SPEC.md — спецификация для человека.
- SITE-SPEC.json — спецификация для Codex и других ИИ-агентов.
- AGENTS.md — обязательные правила изменения проекта.

Правки сайта всегда синхронно вносятся в обе спецификации и в реализацию.

ОСНОВНЫЕ ФАЙЛЫ
- index.html — структура и содержание страницы;
- css/styles.css — оформление и адаптивность;
- js/app.js — меню, вкладки, форма и анимация;
- docs/manuals/ — эксплуатационные руководства;
- docs/marketing/ — дизайн-спецификации, HTML/CSS-исходники и PNG-макеты листовки и буклета;
- docs/Решение-ФСТЭК-7553-18.11.2025.pdf — решение о проведении сертификации.
